1. What you can watch (no login)

This recording is Solari cloud Chrome opening ironadamant.com and checking that the page still says “One office job.” Anyone can watch it. No API key, no account. It proves the public loop: open page, snapshot, independent check, close.

If you expected a login screen, you are in the right place to be confused. That site is not an app. The app is the next section.

2. What the product is for (logged-in SaaS)

Auspex is built for pages behind a login: your own SaaS, a dashboard, Microsoft SSO. You sign in once in a handoff window. Auspex saves the session. Later checks reuse it. The agent never types the password.

Dogfood is ConsistencyHub. We cannot publish a replay of that session (it is a real dashboard). You get a blurred screenshot and an honest receipt instead.

Try the public loop

git clone https://github.com/IronAdamant/auspex.git
cd auspex
npm install
export SOLARI_API_KEY=slr_live_…   # console.getsolari.com
npx auspex check --name ironadamant

That command hits the public site. For a logged-in app you use a saved profile (login → human signs in → finalize-login → check --profile …). ConsistencyHub is one example, not the only host.

Never commit SOLARI_API_KEY, .env, or .auspex/. Never type passwords.
